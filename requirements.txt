# ── FRONTEND (Node.js / Next.js) ───────────────────────────────────────────────
# The main application. Install with:
#
#   cd frontend
#   npm install
#
# Then start the dev server:
#
#   npm run dev
#
# Core packages (managed by npm — see frontend/package.json for full list):
#
#   next@14.2.35                  – React framework (App Router, SSR)
#   react@^18 / react-dom@^18     – UI library
#   typescript@^5                 – Static typing
#   tailwindcss@^3.4.1            – Utility-first CSS
#   tw-animate-css@^1.4.0         – Tailwind animation utilities
#   shadcn@^4.21.0                – Accessible UI components (CLI + primitives)
#   @base-ui/react@^1.8.0         – Headless UI primitives used by shadcn components
#   class-variance-authority@^0.7 – Component variant styling
#   cn@^0.3.2                     – className merge helper (src/lib/utils.ts)
#   lucide-react@^1.47.0          – Icons
#   mapbox-gl@^3.31.0             – Interactive satellite maps
#   @mapbox/mapbox-gl-draw@^1.5.2 – Field boundary drawing tools
#   @turf/turf@^7.4.0             – Geospatial calculations (area, centroid)
#   @tanstack/react-query@^5.103  – Server state management and caching
#
# External services used by the frontend:
#   Mapbox GL tiles + Geocoding API (farm location search)
#   → both require NEXT_PUBLIC_MAPBOX_TOKEN in frontend/.env.local
#
# Node.js version required: v18.17+ or v20+ (LTS)
# npm version required:     v9+ or v10+


# ── BACKEND (Python / FastAPI) ───────────────────────────────────────────────
# A layered FastAPI service in backend/app/ (models/ schemas/ repositories/
# integrations/ services/ routers/ core/). Install with:
#
#   cd backend
#   python -m venv venv
#   venv\Scripts\activate        (Windows)
#   source venv/bin/activate     (Mac / Linux)
#   pip install -r requirements.txt
#
# Then start the dev server:
#
#   uvicorn app.main:app --reload
#
# Core packages (see backend/requirements.txt for the authoritative list):
#
#   fastapi                       – Web framework
#   uvicorn[standard]             – ASGI server
#   pydantic / pydantic-settings  – Data validation and .env-backed settings
#   sqlalchemy[asyncio]           – Async ORM (backend/app/core/database.py)
#   asyncpg                       – Async PostgreSQL driver
#   alembic                       – Async database migrations (backend/alembic/)
#   httpx / requests              – HTTP clients for external API integrations
#
# Python version required: 3.10+
